`indonesia-provinces.geojson` berasal dari [Indonesia-GeoJSON](https://github.com/AlfianAliM/Indonesia-GeoJSON), bersumber dari Laravel Nusa / Peta Nusa. Data berisi 38 provinsi dengan atribut `code`, `name`, dan `level`. Lisensi data: MIT, © Creasi.co - Laravel Nusa, sebagaimana dinyatakan pada README sumber.

Tiga ring poligon yang orientasinya terbalik pada sumber dibalik agar proyeksi D3 menampilkan daratan dengan benar. Koordinat dan batas wilayah tidak diubah.
