# Project Guidelines

## Project Context

This project is a Data Center Monitoring System built with Laravel, Livewire, PostgreSQL, and Tailwind CSS.

Refer to the project documentation for functional requirements, database design, and UI specifications.

## Development Principles

- Follow Laravel conventions and existing Laravel Boost guidelines.
- Write clean, modular, readable, and maintainable code.
- Follow separation of concerns and avoid unnecessary abstractions.
- Reuse existing components and functionality whenever possible.
- Prefer Laravel-native solutions over additional dependencies.
- Keep implementations simple and avoid overengineering.

## Project Documentation

- `docs/PRD.md` — Functional requirements and business rules.
- `docs/DATABASE.md` — Database schema and relationships.
- `docs/DESIGN_SYSTEM.md` — UI specifications and design conventions.
- `tasks/` — Task-specific implementation instructions.

Read only the documentation relevant to the current task.

## Task Execution

- Understand the task requirements before implementation.
- Follow the relevant project documentation.
- Implement only the requested scope.
- Do not modify unrelated functionality.
- Do not introduce dependencies or architectural changes without approval.
- Ask for clarification when requirements conflict or are unclear.
- Run relevant tests and formatting tools after implementation.
- Summarize changes, modified files, and verification results.
